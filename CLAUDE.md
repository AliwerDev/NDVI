# CLAUDE.md

## Design file

The design file for this project is the "NDVI monitoring" Design canvas:
https://claude.ai/artifact/4f7wcYqUcKBjLYRUqr1Cm9

- Draw each new screen or UI change on this canvas first. Start the code only after the user approves the design.
- Add new artboards to this canvas. Do not create a separate canvas.
- Use the colors, fonts, and radius values from `frontend/app/globals.css`.
- Give new artboards the next group number. For example, the NDMI and NDRE screens are group 12 (`12a` to `12d`).
